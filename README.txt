フレカコレクションサイト（スターター）

このフォルダには、白・パステル系のフレカ一覧サイトの土台が入っています。
・マイキャラ6人の切り替え
・コーデ名検索
・フレカ画像一覧
・フレカをタップすると拡大表示
・登録したQR画像も同じ画面に表示

【フレカを追加する】
1. フレカ画像を images フォルダに入れます。例：freca-01.jpg
2. QR画像も images フォルダに入れます。例：qr-01.png
3. data.js を開き、cards 配列の中に次のようなデータを追加します。

{
  characterId: "char1",
  name: "ミントコーデ",
  cardImage: "images/freca-01.jpg",
  qrImage: "images/qr-01.png",
  note: ""
},

最後のデータの末尾にはカンマを付けないようにしてください。
characterId は char1 から char6 を指定します。

【キャラ名を変更する】
data.js の characters 配列内にある「マイキャラ 1」などを好きな名前に変更します。

【公開する前に】
サイトに登録した画像は、サイトを見られる人が保存できる可能性があります。
QRコードを公開すると、他の人が読み取れる可能性もあるので、公開してよい画像だけを登録してください。

このプロジェクトは静的サイトです。index.html、style.css、app.js、data.js、images フォルダをまとめて公開します。
